# Project Rules & Design Guidelines

## Icon & UI Guidelines
- **STRICT PROHIBITION (User's Personal Choice)**: Do **NOT** use the `Sparkles` icon (from `lucide-react` or any other library) anywhere across the entire project. 
- Use clean, minimal, professional icons (e.g., `Activity`, `Calendar`, `TrendingUp`, `CheckCircle2`, `Clock`, etc.) or elegant badge components instead.

## Theme & Dark Mode Standards
- Never use generic flat black/gray for dark mode.
- Use rich obsidian/navy palettes (`#070b14`, `#0c1427`, `#050814`) with translucent glassmorphic surfaces (`backdrop-blur`).
- All interactive cards must have subtle, GPU-friendly static ambient lighting and glow only upon user hover.
